# 🎓 CECyTE 23 - Landing Page

Landing page desarrollada como proyecto personal utilizando HTML, CSS y JavaScript.

## 🚀 Características

- Contadores animados
- Indicador dinámico de estado (Abierto/Cerrado)
- Animaciones al hacer scroll
- Diseño moderno y responsive

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Intersection Observer API

## 📂 Estructura del proyecto
📁 proyecto
├── index.html
├── style.css
├── main.js
## 🎯 Objetivo

Practicar desarrollo frontend, animaciones y manipulación del DOM para crear una experiencia más interactiva y profesional.
